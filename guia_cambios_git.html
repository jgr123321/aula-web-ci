Ejercicios Git: copiar y pegar

Abre index_git_practica.html en VS Code. Haz cada cambio en orden, sin conflictos.

Preparación

Copia index_git_practica.html a C:\CursoDocker\web, ejecuta los siguientes comandos si este archivo aún no está en Git:

cd C:\CursoDocker\web
git switch main
git add index_git_practica.html
git commit -m "Añadir HTML inicial para practicar"
Si ya está añadido y confirmado, omite el add y commit iniciales.

1. Cambiar título

Buscar en el original:

<h1>Práctica Git - Versión Inicial</h1>

Sustituir por (copiar y pegar):

<h1>Laboratorio de Git y GitHub</h1>

Comandos Git:

git switch main
git switch -c cambio-1-titulo
# Edita y guarda el archivo usando el fragmento anterior
git diff
git add index_git_practica.html
git commit -m "Ejercicio 1: Cambiar título"
git switch main
git merge cambio-1-titulo
